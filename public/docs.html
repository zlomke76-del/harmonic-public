Harmonic v4 public architecture contract

Govern continuation before consequence.

The production Harmonic boundary evaluates whether the conditions supporting a proposed continuation remain admissible at the moment consequence is about to bind.

Repository boundary: the evaluator source included in this public repository is a simplified public-safe demonstrator. It is not the sovereign production Harmonic v4 runtime.

Temporal Standing

T₀ → ΔN → Tₙ

Temporal Standing asks whether standing legitimately established at T₀ still survives a material change ΔN for an exact consequence at Tₙ.

Historical validity receives no automatic persistence. A material change may preserve standing, defeat standing, or leave standing unresolved. The system must discriminate among those conditions for the exact consequence being governed.

Temporal Standing is a governance determination property. It does not, by itself, establish downstream execution enforcement.

T₀ → ΔN → Tₙ

what was authorized then
        ↓
what materially changed
        ↓
does that authority still stand
for this exact consequence now?

Disambiguation: Temporal Standing is distinct from software projects named “Standing,” temporal databases, workflow engines, time-limited permission leases, and continuous runtime monitoring architectures. It does not require that every change automatically invalidates authority.

Execution boundary

A determination does not claim that Harmonic performed the downstream act. The v4 public contract separates response binding from downstream execution enforcement.

{
  "runtime_version": "4.0.0",
  "outcome": "ESCALATED",
  "admissible": false,
  "action": "escalate",
  "response_binding": {
    "response_binding_enforced": true,
    "binding_scope": "governed_response_contract_only",

  },
  "constitutional_transaction": {
    "api_version": "v4-single-call",

  }
}

Present-state discipline

Upstream cognition or institutional systems establish attributable state. Harmonic evaluates continuation against the supplied state and preserves epistemic/reconstructability limits rather than silently manufacturing missing institutional knowledge.

Public frozen evidence

The Decision Engineering T4 v1.1 archive is preserved under evidence/decision-engineering/t4-v1.1/. It records both supportive and non-supportive findings. The final bounded reading is:

  • D1: representation-activation bundle effect supported; individual field causality not isolated.
  • D2: propagation dependency demonstrated at the signal/reason level; top-line marginal effect not isolated.
  • D3: provenance dependency not demonstrated; provenance-projection insensitivity observed.

The archive is evidence only. It is not runtime configuration and was added after the v4.0.0 runtime freeze.

Reference/demo endpoint in this repository

The checked-in api/evaluate.js endpoint remains available for local public-safe experimentation and SDK wiring. Its simplified scoring logic is intentionally not represented as the private production primitive implementation. Results from that local demonstrator are not production Harmonic evidence.
